vitRemote troubleshooting patch
===============================

Changes in this ZIP:
- Normalize H.264 SPS/PPS separately because some Android MediaCodec implementations
  provide codec-specific data without Annex-B start codes.
- Add a raw-NAL fallback in SpsFix.
- Add browser decoder fallback: if WebCodecs cannot configure/decode H.264, the viewer
  switches to the MediaSource player and requests a fresh keyframe.
- Show a useful status message if the phone connects but no video configuration/frames arrive.
- Keep the app's bundled viewer and Cloudflare hosted viewer HTML in sync.

Validation:
- JavaScript syntax checked with Node.js.
- Android Gradle build could not be run in this environment because the Gradle distribution
  could not be downloaded (network DNS unavailable). Use the repository's GitHub Actions
  Android APK Build workflow to compile the APK.

Important:
- Cloudflare Worker must already be deployed with the same PAIRING_SECRET configured on
  the Worker and in RelayConfig.kt / viewer HTML. Do not share that secret publicly.


Relay video fix (2026-11-17): RemoteService.liveClients() now includes relayClient as well as direct WebServer clients. This allows Cloudflare-connected viewers to trigger MediaProjection/encoder startup and receive H.264 config and frames. Not built or device-tested in this environment.
